# 书签管理 bookmark-manager

一个**纯静态**的书签管理单页应用，只有 `index.html`、`style.css`、`app.js`、`README.md` 四个文件。
没有任何构建步骤、框架依赖和后端服务，双击打开即用，所有数据保存在浏览器 localStorage 中。

## 功能特性

- **书签管理**：添加、编辑、删除书签，字段包括标题、网址、分类、备注
- **分类筛选**：按分类下拉筛选，选项自动从现有书签中生成并显示数量
- **关键词搜索**：实时匹配标题、网址、分类、备注
- **点击直达**：点击书签标题或网址即可在新标签页打开
- **数据持久化**：全部数据存于 localStorage，刷新、关闭浏览器后不丢失
- **JSON 导出**：一键把全部书签下载为 JSON 文件备份
- **JSON 导入**：从 JSON 文件导入书签，自动按网址去重、跳过无效条目
- **内置示例**：首次访问自动写入 8 条示例书签，方便快速上手
- 其他细节：网址自动补全 `https://` 前缀、重复网址校验、删除二次确认、深色模式自适应、移动端适配、防 XSS 转义

## 快速开始

方式一：直接用浏览器打开 `index.html`（双击即可）。

方式二（推荐，体验与线上一致）：

```bash
cd bookmark-manager
python3 -m http.server 8080
# 然后访问 http://127.0.0.1:8080
```

## 文件结构

```
bookmark-manager/

```

## 使用说明

- **添加**：点击右上角「＋ 添加书签」，填写标题（必填）和网址（必填），分类可输入新分类或从下拉建议中选择。
- **编辑 / 删除**：每张卡片底部的「编辑」「删除」按钮；删除前会弹出二次确认。
- **搜索与筛选**：顶部搜索框输入关键词实时过滤；右侧下拉按分类过滤，两者可叠加使用。
- **导出**：点击「导出」按钮，浏览器会下载形如 `bookmarks-2026-10-25-12-00-00.json` 的文件。
- **导入**：点击「导入」选择 JSON 文件。导入采用**合并**策略：与现有书签网址相同的条目会被跳过，不会覆盖已有数据；确认弹窗会先告知将新增几条、跳过几条。

## 数据存储

- 存储位置：浏览器 `localStorage`，键名为 `bookmark-manager:bookmarks:v1`。
- 首次访问时自动写入 8 条示例书签；此后完全由你管理，即使删光所有书签也不会再自动补示例。
- 数据只存在于当前浏览器的当前源下：更换浏览器、更换设备或清除站点数据都会丢失，**请定期导出 JSON 备份**。

## JSON 数据格式

导出文件格式如下（导入时也兼容纯数组格式，且 `id`、`createdAt` 可省略）：

```json
{
  "app": "bookmark-manager",
  "version": 1,
  "exportedAt": "2026-10-25T04:00:00.000Z",
  "bookmarks": [
    {
      "id": "bm-abc123-xyz",
      "title": "GitHub",
      "url": "https://github.com",
      "category": "开发工具",
      "notes": "全球最大的代码托管与协作平台",
      "createdAt": 1761340800000
    }
  ]
}
```

## 隐私与安全

- 不发起任何网络请求，不使用任何第三方服务，数据完全留在本地。
- 渲染时对用户输入统一做 HTML 转义，避免注入；外链使用 `target="_blank" rel="noopener noreferrer"`。

## 兼容性

支持 evergreen 现代浏览器（Chrome / Edge / Firefox / Safari 最新版）。依赖的 `localStorage`、`Blob`、`URL.createObjectURL`、ES6+ 均为多年前的标准能力，无兼容性问题。
